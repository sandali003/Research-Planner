Is this vehicle wearing out faster than other vehicles of the same age and mileage? The model estimates the expected condition from age and mileage, the observed condition from inspection evidence, and flags accelerated deterioration when observed falls clearly below expected.

Component flow

Input vehicle age, mileage and profile
Receive cleaned OBD-II, service and inspection features
Estimate expected condition for comparable age/mileage
Estimate observed condition from current evidence
Calculate deterioration deviation (observed − expected)
Classify as normal or accelerated deterioration, with reasons
Send the result to the AutoSense platform
